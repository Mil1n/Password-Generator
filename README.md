# MilinPass 🔐

**MilinPass** — современный генератор паролей в стиле single-page app.

## Что умеет

- ⚡ Быстро генерирует случайные пароли с настраиваемой длиной (8–64).
- 🧩 Позволяет выбрать состав пароля:
  - заглавные буквы `A–Z`
  - строчные буквы `a–z`
  - цифры `0–9`
  - специальные символы
- 👀 Может исключать похожие символы (`O`, `0`, `I`, `l`, `1`).
- 📝 Имеет режим **passphrase** для удобочитаемых фраз-паролей.
- 📊 Показывает визуальную оценку силы пароля.
- 📋 Поддерживает копирование в буфер обмена одной кнопкой.
- 🕘 Сохраняет локальную историю последних 10 сгенерированных значений.

## Как запустить

1. Склонируйте репозиторий.
2. Откройте файл `index.html` в браузере.

Никаких зависимостей и сборки не требуется — всё работает прямо из коробки.

## Безопасность

- Для генерации случайности используется `crypto.getRandomValues`.
- История хранится только локально в браузере (`localStorage`) и не отправляется на сервер.

## Технологии

- HTML5
- CSS3
- Vanilla JavaScript
