# MilinPass 🔐

**MilinPass** — современный генератор паролей в стиле single-page app с PWA-режимом, локальными настройками, приватной историей и тестируемой логикой генерации.

## Что умеет

- ⚡ Быстро генерирует случайные пароли с длиной 12–64 символа.
- 🧩 Позволяет выбрать состав пароля: `A–Z`, `a–z`, цифры и специальные символы.
- 🎛️ Имеет готовые пресеты: максимальная безопасность, читаемый пароль, ограничения сайтов, буквы/цифры и passphrase.
- 🧱 Поддерживает правила совместимости сайтов: собственный набор спецсимволов, минимум цифр и минимум спецсимволов.
- 👀 Может исключать похожие символы (`O`, `0`, `I`, `l`, `1`) и маскировать текущий пароль на экране.
- 📝 Имеет настраиваемый режим **passphrase**: 3–6 слов, разделитель, словарь, регистр, число и спецсимвол.
- 📊 Показывает визуальную оценку силы пароля, примерную энтропию, чек-лист требований и предупреждения о слабых настройках.
- 📋 Поддерживает копирование текущего пароля и записей истории с fallback для старых браузеров.
- 🕘 История отключена по умолчанию, может сохранять локально последние 10 значений и очищаться одной кнопкой.
- 🧹 Поддерживает автоочистку текущего пароля по таймеру.
- 🌓 Поддерживает светлую/тёмную тему, экспорт/импорт настроек и сброс локального состояния.
- 📱 Работает как PWA и может открываться офлайн после первой загрузки.

## Как запустить

1. Склонируйте репозиторий.
2. Откройте файл `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

Никаких зависимостей и сборки не требуется — всё работает прямо из коробки.

## Безопасность

- Для генерации случайности используется `crypto.getRandomValues` без modulo bias: значения, которые могут исказить распределение, отбрасываются.
- Генератор гарантирует минимум по одному символу из каждого выбранного набора и учитывает дополнительные требования совместимости, а затем перемешивает результат алгоритмом Fisher–Yates.
- Энтропия passphrase считается от размера словаря и количества слов, а не только от длины итоговой строки.
- Приложение показывает предупреждение, если Web Crypto API недоступен.
- История отключена по умолчанию. Если включить её вручную, данные хранятся только локально в браузере (`localStorage`) и не отправляются на сервер.
- В HTML задан базовый Content Security Policy, ограничивающий загрузку ресурсов текущим origin.
