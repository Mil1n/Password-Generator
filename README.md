# MilinPass 🔐

**MilinPass** — современный генератор паролей в стиле single-page app.

## Что умеет

- ⚡ Быстро генерирует случайные пароли enterprise-профиля с длиной 12–20 символов.
- 🧩 Позволяет выбрать состав пароля:
  - заглавные буквы `A–Z`
  - строчные буквы `a–z`
  - цифры `0–9`
  - специальные символы
- 👀 Может исключать похожие символы (`O`, `0`, `I`, `l`, `1`).
- 📝 Имеет режим **passphrase** для удобочитаемых фраз-паролей.
- 📊 Показывает визуальную оценку силы пароля, примерную энтропию и чек-лист требований.
- 📋 Поддерживает копирование в буфер обмена одной кнопкой с fallback для старых браузеров.
- 🕘 Сохраняет локальную историю последних 10 сгенерированных значений и позволяет очистить её.

## Как запустить

1. Склонируйте репозиторий.
2. Откройте файл `index.html` в браузере.

Никаких зависимостей и сборки не требуется — всё работает прямо из коробки.

## Безопасность

- Для генерации случайности используется `crypto.getRandomValues` без modulo bias: значения, которые могут исказить распределение, отбрасываются.
- Генератор гарантирует минимум по одному символу из каждого выбранного набора, а затем перемешивает результат алгоритмом Fisher–Yates.
- История хранится только локально в браузере (`localStorage`) и не отправляется на сервер.
